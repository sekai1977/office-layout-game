# オフィスを作れ！
オフィスコーポレーション向けの提案用ゲーム試作。公式採用選考ではありません。
5種類の部屋に家具を選んで配置。配置済み家具を選択して移動・回転・返却できます。各部屋の配置はブラウザ内に保存されます。
必要家具25点、入口から家具の操作面までの通路30点、家具の操作面と机・椅子の組み合わせ30点、向きのまとまり15点。必要家具が足りない場合は最大79点。80点以上で面接へのメッセージと公式HPリンクを表示。
机のモニター側が奥、反対側が椅子を置く正面。椅子の背もたれの反対側に通路を空けます。
入口は青いマス。家具の重なり・入口・部屋外への配置を禁止。
ローカル起動：試作を見る.command。Python3が必要。編集本体はapp.js / rules.js / style.css。
Three.jsはvendorに同梱。ライセンスはvendor/LICENSE-three.txt。
